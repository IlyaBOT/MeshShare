MeshShare is a Meshtastic-compatible Android client focused on reliable direct peer-to-peer file transfer over low-bandwidth, off-grid LoRa networks. Normal Meshtastic messaging, node management, and radio configuration remain available.

MeshShare file transfer is designed for one sender and one concrete receiver. It is disabled for channels, group chats, and broadcast destinations. Files are split into small radio packets with integrity checking, loss recovery, resynchronization, conservative pacing, and optional compression. No custom Meshtastic firmware is required.

<b>Development status</b>

The MeshShare rewrite is in progress. File transfer is not yet ready for production or safety-critical use. Build, automated-test, emulator, and real-radio results are tracked separately for each development release.
